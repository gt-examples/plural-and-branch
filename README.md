# Plural and Branch Demo

A minimal Next.js app demonstrating the `<Plural>` and `<Branch>` components from [gt-next](https://www.generaltranslation.com/docs).

## Features

- **Plural**: Handles singular/plural/zero forms for notification counts across languages
- **Branch**: Renders different translated content based on notification type (message, alert, update)
- **Num**: Locale-aware number formatting
- **Var**: Safe variable interpolation inside translated content

## Getting Started

```bash
npm install
npm run dev
```

## Deployment

Deployed at [plural-and-branch.generaltranslation.dev](https://plural-and-branch.generaltranslation.dev)
